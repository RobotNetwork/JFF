      How it works

      Two screens: what the page does, and what lands on the clipboard.

      ServiceNow setup

      Three admin-controlled properties decide whether the pasted markup renders. They live in System Properties > All Properties (sys_properties.list), or in Instance Security Center.

      glide.ui.security.allow_codetag
      Renders HTML inside [code] tags. Default true; many security baselines set it false, and the tags then appear as plain text.
      glide.html.sanitize_all_fields
      Runs journal HTML through the sanitizer, which removes disallowed elements and attributes. The allow and deny lists live in the HTMLSanitizerConfig script include under System Definition > Script Includes.
      glide.ui.journal.use_html
      Set to true to add a rich text editor to journal fields in the Activity stream. Optional; this page works without it, and many large enterprises leave it off because it changes the field for everyone.

      If a tag disappears after posting, the sanitizer or allow_codetag is the place to look. Scripts are never part of the output.

      How it works

      What this tool does

      ServiceNow shows Work notes and Additional Comments as plain text, but renders HTML in those fields when it sits inside [code][/code]. This page writes that markup for you and copies it to the clipboard.

      What lands on the clipboard

      Copy [formatted] (Ctrl+Alt+C) puts plain text on the clipboard, with each formatted block inside a visible [code] tag pair: 

      [code]<h2>Deploy complete</h2>[/code]
Version [code]<b>2.4.1</b>[/code] is live in production.
[code]<ul><li>Cache cleared</li><li>Smoke tests passed</li></ul>[/code]

      ServiceNow renders those blocks as HTML. Preview shows the same entry the way the journal field will show it. Paste into Work notes or Additional comments and post.
